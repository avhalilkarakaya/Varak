# Kod imzalama politikası / Code signing policy

## Türkçe

Varak'ın Windows sürümlerinin SignPath Foundation programıyla imzalanması planlanmaktadır.
Program kabul ederse bu sayfada şu ifade yer alacaktır: "Free code signing provided by
SignPath.io, certificate by SignPath Foundation."

- İmzalanan dosyalar yalnızca bu depodaki kaynak koddan GitHub Actions ile otomatik derlenen
  sürümlerdir (`.github/workflows/derle.yml`).
- Her imzalama isteği, aşağıdaki onaylayıcı tarafından elle onaylanır.
- Ekip üyelerinin tümü GitHub ve SignPath hesaplarında iki aşamalı doğrulama kullanır.

- İnceleyenler (Reviewers): Halil KARAKAYA
- Onaylayanlar (Approvers): Halil KARAKAYA

## English

Windows releases of Varak are planned to be signed through the SignPath Foundation program.
If accepted, this page will state: "Free code signing provided by SignPath.io, certificate by
SignPath Foundation."

- Only releases built automatically by GitHub Actions from the source code in this repository
  (`.github/workflows/derle.yml`) are signed.
- Every signing request is approved manually by the approver listed below.
- All team members use multi-factor authentication for GitHub and SignPath.
